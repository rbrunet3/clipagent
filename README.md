# ClipAgent site

Public pages for ClipAgent's Google and Meta app settings: home page, privacy policy, terms, data deletion, and the
Instagram sign-in callback. Served by GitHub Pages at https://rbrunet3.github.io/clipagent/.

The source lives in the private ClipAgent repo under `site/`; the public repo `rbrunet3/clipagent` is a copy of that
folder. To update it: `uv run clipagent site-publish` is not a thing; copy the folder into a clone of
rbrunet3/clipagent, commit and push.
